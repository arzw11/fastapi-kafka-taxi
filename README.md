# FastAPI + Kafka Taxi Application
Это pet-проект, который реализует серверную часть сервиса заказа такси на `Python`. Проект начат для изучения современных подходов к разработке backend-приложений. Проектирование `REST API`, обмен сообщениями через `Apache Kafka`, построение событийно-ориентированной архитектуры, работа с базами данных.

## Необходимые зависимости:

- [Python 3.12](https://www.python.org/downloads/release/python-3120/)
- [Docker Compose](https://docs.docker.com/compose/install/)
- [GNU Make](https://www.gnu.org/software/make/)
